# HTML Action Card

El componente `HtmlActionCard` permite mostrar una tarjeta interactiva en mensajes de tipo HTML cuando incluyes un objeto `htmlAction`. Es perfecto para:

- Descargas de archivos
- Enlaces a recursos externos
- Acciones de generación de contenido
- Navegación a dashboards o aplicaciones
- Ejecución de comandos o procesos

## Estructura Básica

```typescript
{
  id: '1',
  role: 'assistant',
  type: 'html',
  content: 'Descripción del contenido',
  htmlAction: {
    id: 'unique-action-id',
    title: 'Título de la acción',
    subtitle: 'Subtítulo opcional',
    icon: 'Code2', // Icono de Lucide (opcional)
  }
}
```

## Propiedades de HtmlMessageAction

| Propiedad | Tipo | Requerida | Descripción |
|-----------|------|----------|-------------|
| `id` | string | ✓ | Identificador único para la acción |
| `title` | string | ✓ | Título mostrado en la tarjeta |
| `subtitle` | string | ✗ | Subtítulo o descripción adicional |
| `icon` | string | ✗ | Nombre del icono de Lucide (por defecto: 'Code2') |

## Personalizaciones Disponibles

### Iconos de Lucide

Puedes usar cualquier icono de [Lucide Icons](https://lucide.dev). Algunos populares:

- `Code2` - Código
- `File` - Archivo genérico
- `FileText` - Documento de texto
- `Image` - Imagen
- `Github` - GitHub
- `BarChart3` - Gráficos/Analytics
- `BookOpen` - Documentación
- `Download` - Descargar
- `ExternalLink` - Enlace externo
- `Play` - Reproducir
- `Settings` - Configuración
- `Database` - Base de datos
- `Key` - Contraseña/API Key
- `Shield` - Seguridad
- `Zap` - Potencia/Acción rápida

### Manejador de Eventos

```typescript
<ChatWindow
  messages={messages}
  onMessageActionClicked={(message, action) => {
    console.log('Acción ejecutada:', action.title)
    
    // Ejemplo: diferentes acciones por tipo
    switch(action.id) {
      case 'download-code':
        downloadCode(message)
        break
      case 'open-repo':
        window.open(action.subtitle)
        break
      case 'open-dashboard':
        navigateToDashboard()
        break
    }
  }}
/>
```

## Casos de Uso Reales

### Generación de Contenido
Cuando el AI genera código, documentos o archivos, muestra una tarjeta con opción de descarga inmediata.

### Recursos Externos
Vincula a GitHub, documentación, wikis, o dashboards relevantes sin salir del chat.

### Flujos de Trabajo
Ejecuta acciones como crear branches, deployments, o procesos en segundo plano.

### Información Estructurada
Presenta datos importantes de manera clara y accionable con un CTA (Call To Action) evidente.

## Props Completos

```typescript
interface HtmlMessageAction {
  /** Identificador único de la acción */
  id: string
  /** Título que se muestra en la tarjeta */
  title: string
  /** Subtítulo o descripción adicional */
  subtitle?: string
  /** Icono de Lucide (por defecto: 'Code2') */
  icon?: string
}

interface Message {
  // ... otras props
  type?: 'text' | 'html'
  /** Muestra acción en lugar del contenido HTML */
  htmlAction?: HtmlMessageAction
}

interface ChatMessageListProps {
  // ... otras props
  /** Callback cuando se hace clic en una acción HTML */
  onMessageActionClicked?: (message: Message, action: HtmlMessageAction) => void
}
```

## Consejos de Diseño

1. **Títulos claros**: Usa verbos activos ("Descargar", "Abrir", "Ver")
2. **Subtítulos informativos**: Incluye tipo, tamaño, o contexto
3. **Iconos relevantes**: Elige iconos que comuniquen la acción instantáneamente
4. **Una acción por mensaje**: Mantén un CTA por mensaje para evitar confusión
5. **Orden lógico**: Coloca la información más importante en el título

## Styling

El componente hereda los estilos del widget y se adapta automáticamente al tema. Puedes personalizar mediante CSS variables:

- `--ltb-foreground` - Color del texto
- `--ltb-border` - Color del borde
- `--ltb-muted-foreground` - Color del subtítulo
